## How to Use This Guide

### Search Volume Tiers

| Tier          | Monthly Searches | Usage                                                 |
| ------------- | ---------------- | ----------------------------------------------------- |
| **Primary**   | 50,000           | Main page titles, H1 headings, hero sections          |
| **Secondary** | 5,000            | H2 subheadings, blog titles, supporting content       |
| **Long-tail** | 500              | FAQ questions, blog subtopics, specific landing pages |

### Search Intent Types

| Intent                       | Description                          | Content Type                        |
| ---------------------------- | ------------------------------------ | ----------------------------------- |
| **Informational**            | Learning about procedures            | Blog posts, FAQ sections, guides    |
| **Commercial Investigation** | Comparing options, researching costs | Procedure pages, comparison content |
| **Transactional**            | Ready to book/contact                | Landing pages, contact pages        |
| **Navigational**             | Looking for specific clinic/surgeon  | About page, surgeon pages           |

### Competition Levels

| Level              | Indexed Value   | Strategy                                 |
| ------------------ | --------------- | ---------------------------------------- |
| **Low** (0-33)     | Easier to rank  | Target quickly, good for new content     |
| **Medium** (34-66) | Moderate effort | Build with quality content               |
| **High** (67-100)  | Competitive     | Long-term strategy, high-quality content |

## Keyword Combinations

### Recommended Title Formulas

**Procedure Pages:**

```
[Procedure] in Miami | [Brand] - [Unique Value Prop]
Example: "Brazilian Butt Lift in Miami | Alluring Plastic Surgery"
```

**Blog Posts:**

```
[Procedure] [Topic]: [Benefit/Promise] | [Brand]
Example: "BBL Recovery: Your Week-by-Week Guide | Alluring Plastic Surgery"
```

**Cost/Pricing Content:**

```
How Much Does a [Procedure] Cost in Miami? [Year] Guide
Example: "How Much Does a Mommy Makeover Cost in Miami? 2025 Guide"
```

### High-Converting Keyword Combinations

| Combination                    | Use Case            | Search Intent |
| ------------------------------ | ------------------- | ------------- |
| [procedure] + miami            | Procedure pages     | Transactional |
| [procedure] + before and after | Gallery pages       | Informational |
| [procedure] + cost + miami     | Pricing content     | Commercial    |
| [procedure] + financing        | Financing pages     | Commercial    |
| best + [procedure] + miami     | Competitive content | Transactional |
| [procedure] + recovery + time  | Blog posts          | Informational |

### Long-tail Keyword Templates

**For FAQ Sections:**

- "How much does [procedure] cost in Miami?"
- "How long is [procedure] recovery?"
- "Am I a candidate for [procedure]?"
- "What is included in a [procedure]?"
- "Is [procedure] safe?"

**For Blog Posts:**

- "[Procedure] in Miami: Complete Guide [Year]"
- "[Procedure] Before and After: Real Patient Results"
- "[Procedure] Recovery: What to Expect Week by Week"
- "[Procedure] vs. [Alternative]: Which Is Right for You?"
- "Financing Your [Procedure]: Options and Tips"
